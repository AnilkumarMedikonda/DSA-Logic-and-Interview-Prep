## 🧩 How I Solved Problems

My thinking process:

1. Understand problem / pattern
2. Do dry run manually
3. Break into loops
4. Write clean logic (no hardcoding)
5. Optimize if possible

## ⚙️ Key Learnings

* Always find **midpoint** in patterns
* Avoid hardcoding (`i == 5` ❌)
* Prefer **mathematical logic**
* Use safe loops (`0..<n`)
* Build logic first → code next

---

#### ⏱️ Time Complexity

Understanding how fast code runs:

* **O(1)** → Constant time
* **O(log n)** → Logarithmic (Binary Search)
* **O(n)** → Linear (single loop)
* **O(n²)** → Nested loops

👉 Goal:

* Reduce brute force
* Optimize logic

---

#### 📦 Space Complexity

Understanding memory usage:

* **Auxiliary Space** → Extra memory used
* **O(1)** → In-place
* **O(n)** → Extra storage / recursion

---

#### 🔄 In-Place vs Extra Memory

* **In-Place** → No extra memory
* **Extra Space** → Uses additional structures

👉 Goal:

* Prefer in-place solutions

---

#### 🧠 Recursion & Stack Understanding

* Uses **call stack memory**
* Each call adds space → O(n)
* Focus on:

  * Base case
  * Stack flow
  * Backtracking

---

#### 🔹 Data Structure Complexity Awareness

* **Array** → O(1) access, O(n) insert/delete
* **Stack** → O(1) push/pop
* **Queue** → O(1) enqueue/dequeue
* **Linked List** → O(1) insert (with reference), O(n) traversal

---

### 🎯 Final Focus

* Write optimized solutions
* Analyze time & space before coding
* Move from brute force → optimal approach

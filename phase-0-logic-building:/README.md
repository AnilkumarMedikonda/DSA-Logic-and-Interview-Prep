# 📒 Phase 0 – Logic Building (Loops & Patterns)

---

## 🧠 Objective

Build a strong foundation in:

* Loop thinking
* Iteration logic
* Dry-run ability

This phase focuses on understanding how to **break problems into steps using loops**.

---

## 📌 Topics Covered

* While Loop
* Repeat-While Loop
* For Loop
* Nested Loops
* Break & Continue
* Mathematical Series
* Mixed Logical Problems
* Star Patterns

---

## 🧩 How I Approached Problems

1. Understand the problem
2. Do a manual dry run
3. Break into loops
4. Write clean logic (no hardcoding)
5. Optimize if possible

---

## ⚙️ Key Learnings

* Importance of dry run before coding
* How to identify loop patterns
* Avoiding hardcoded values (`i == 5` ❌)
* Writing reusable and scalable logic
* Understanding pattern symmetry

---

## ⏱️ Complexity Insight

* Most problems → **O(n)**
* Pattern problems → **O(n²)**
* Space → mostly **O(1)**

---

## 🔥 Outcome

After completing this phase, I can:

* Solve loop-based problems confidently
* Build different types of patterns
* Debug and improve basic logic

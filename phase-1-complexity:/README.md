## ⏱️ Time Complexity

Measures how operations grow with input size.

### Common Types:

* O(1) → Constant
* O(log n) → Logarithmic
* O(n) → Linear
* O(n log n) → Efficient
* O(n²) → Nested loops
* O(2ⁿ) → Exponential

---

## 📦 Space Complexity

Measures extra memory used by the algorithm.

### Key Points:

* Only **auxiliary space** is counted
* Input memory is not counted
* Recursion uses stack memory

---

## 🔄 In-Place vs Extra Space

* In-place → O(1), no extra memory
* Extra space → O(n), uses additional structures

---

## 🧠 Key Learnings

* Identify complexity from loops and recursion
* Ignore constants and smaller terms
* Focus on dominant growth
* Recognize log patterns (divide by 2)
* Understand recursion stack usage

---

## 🔍 Identification Rules

* One loop → O(n)
* Nested loops → O(n²)
* Divide by 2 → O(log n)
* Loop + log → O(n log n)
* Recursion → analyze calls and depth

---

## ⚠️ Common Mistakes

* Writing O(n/2) instead of O(n)
* Ignoring recursion stack space
* Confusing O(n log n) with O(n²)
* Counting input as space

## 🧩 How I Approached Problems

1. Understand the problem
2. Perform a dry run
3. Start with brute force solution
4. Avoid built-in methods initially
5. Optimize using better logic
6. Analyze time & space complexity
7. Handle edge cases properly

## ⏱️ Complexity Insight

* Traversal problems → **O(n)**
* Nested loop problems → **O(n²)**
* Two Pointer problems → **O(n)**
* Space:
  * Basic problems → **O(1)**
  * Result string / array problems → **O(n)**
